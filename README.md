# 🌦️ Weather Forecasting Web Application

A modern, responsive, and user-friendly Weather Forecasting Web Application that provides real-time weather updates for any city worldwide. This project demonstrates the use of REST APIs, asynchronous JavaScript, and clean UI design.

## 📌 Overview

The Weather Forecasting Web App allows users to search for any city and get accurate, real-time weather information including temperature, weather conditions, humidity, and more. It is built with a focus on simplicity, performance, and responsiveness.

## ✨ Key Features

* 🔍 **City-based Weather Search**
* 🌡️ **Real-time Temperature Display**
* ☁️ **Dynamic Weather Conditions (Cloudy, Sunny, Rainy, etc.)**
* 💧 **Humidity & Wind Speed Information**
* 🕒 **Live Date and Time Display**
* 📱 **Fully Responsive Design (Mobile + Desktop)**
* ⚡ **Fast API Integration with Async/Await**
* ❌ **Error Handling for Invalid City Names**

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/ashusingh41537-arch/weather-forecasting-web-project.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd weather-forecasting-web-project
```

### 3️⃣ Open in Browser

Simply open:

```
index.html
```
## 🔑 API Configuration

1. Get your API key from any provider (e.g., OpenWeatherMap)
2. Open `script.js`
3. Replace the API key:

```javascript
const apiKey = "YOUR_API_KEY_HERE";
```
